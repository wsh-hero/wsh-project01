## 总结
实现一个可运行的浏览器端像素风机甲对战 Demo：同屏双人对战，支持移动、攻击、防御、冲刺/重击（L），包含血量、受击反馈与胜负结算；画面为赛博霓虹像素风，带基础场景与角色动画。

## 玩法设计（可实现且足够“像游戏”的最小闭环）
### 目标与胜负
- 每个机甲初始血量 100。
- 任一方血量降至 0 触发胜负：显示“P1 WIN / P2 WIN”，冻结输入与物理更新；按 R 重开。

### 场地与移动
- 俯视角小型竞技场（屏幕内矩形边界），避免跳跃/平台物理复杂度。
- 移动：8 向（WASD / 方向键），对角线速度归一；边界碰撞限制在场内。
- 面朝：根据最近一次非零移动方向决定（影响攻击朝向与攻击判定区域）。

### 战斗（最小但有博弈）
- 轻攻击（J / P2: 1）
  - 短前摇 + 短持续判定，命中造成伤害与小击退。
  - 冷却时间限制连按刷屏。
- 防御（K / P2: 2）
  - 按住进入防御姿态，移动速度降低。
  - 受到攻击时伤害降低（例如 60% 减伤）并取消/降低击退。
- 冲刺/重击（L / P2: 3）
  - 冲刺：短时间快速位移，带无敌帧或抗打断（选择其一，见“决策”）。
  - 若冲刺命中对方或在冲刺结束立刻接攻击，产生更强击退/更高伤害（形成简单连段空间）。

### 反馈与动画
- 受击闪白/抖动（短时）、命中火花像素特效、屏幕轻微震动（可选）。
- HUD：血条、技能冷却提示（至少显示冲刺冷却）、胜负提示。

### 默认键位（确认项）
- P1：W/A/S/D 移动；J 轻攻击；K 防御（按住）；L 冲刺/重击。
- P2：↑/↓/←/→ 移动；1 轻攻击；2 防御（按住）；3 冲刺/重击。

## 核心代码结构（面向可维护的最小拆分）
### 工程形态
- 前端：React + TypeScript + Vite + Tailwind；无后端。
- 渲染：单一 `<canvas>` 像素渲染（`image-rendering: pixelated`），HUD/菜单用 React 覆盖层。

### 建议目录（将创建）
- `src/pages/GamePage.tsx`：页面骨架（标题、HUD、按键说明、重开提示）。
- `src/components/GameCanvas.tsx`：Canvas 初始化、输入采集、启动/停止主循环、与引擎桥接。
- `src/store/useGameUiStore.ts`：zustand 存储 UI 侧可观察状态（hp、winner、cooldown、paused）。
- `src/game/types.ts`：Vec2、Rect、Player、Input、GameState 等类型。
- `src/game/config.ts`：平衡参数（速度、伤害、减伤比例、各类 CD、判定尺寸、调色板）。
- `src/game/input.ts`：键位映射与 InputState 合并（P1/P2）。
- `src/game/engine.ts`：纯逻辑更新（step）、碰撞/命中判定、胜负结算、事件输出（受击/击杀/火花）。
- `src/game/render/renderer.ts`：像素渲染（背景、机甲、特效、血条）。
- `src/game/render/sprites.ts`：基础像素素材（用“像素矩阵 + 调色板”描述的最小 sprite sheet）。
- `src/game/render/effects.ts`：火花/护盾闪烁等短生命周期特效。

### 数据流与边界
- 主循环（`requestAnimationFrame`）仅在 `GameCanvas` 内运行；引擎持有可变 `GameState`（`useRef`），避免 React 每帧重渲染。
- 引擎每 N 帧/或每次关键事件推送一个轻量 `UiSnapshot` 到 zustand（hp、winner、cooldown），HUD 响应式更新。

## 基础素材方案（不依赖外部图片，也可后续替换）
### 画面规格
- 逻辑分辨率：320×180（16:9），再按整数倍缩放到容器，确保像素清晰。
- 调色板：赛博霓虹风（黑/深蓝底，青/紫/粉为高光，黄用于爆炸火花）。

### 精灵资源（用代码内像素矩阵描述）
- 机甲 A（P1，青色系）：32×32
  - 动画：idle(2 帧)、walk(4 帧)、attack(3 帧)、defend(2 帧)、dash(2 帧)、hit(1 帧)。
- 机甲 B（P2，紫色系）：同规格同帧数，换色与少量轮廓差异以区分。
- 特效
  - 命中火花：16×16（2–3 帧循环或一次性）。
  - 护盾闪：覆盖轮廓的 1–2 帧。
- 场景
  - 地面霓虹网格：程序化绘制（像素线条 + 轻微噪点）。
  - 远景楼群：低频像素块剪影（可用固定种子随机生成）。

### 替换路径
- 若后续要换成图片 sprite sheet：保持 sprite 命名与帧索引不变，只替换 `sprites.ts` 的像素数据加载方式（例如改为 Image + atlas）。

- 已锁定：本地双人对战；默认键位为 WASD+J/K/L；主题为赛博霓虹像素风。
- 决策（执行时将按此实现，避免中途再做选择）：
